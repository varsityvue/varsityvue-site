# Team Feed phase plan

Status: Phase 1 SHIPPED; activation NOW / OPERATIONS; Phase 2 CONDITIONAL / DEFERRED. Updated September 30, 2026. Priorities: [ROADMAP.md](ROADMAP.md).

Phase 1 provides administrator-controlled VarsityVue content publishing with canonical school/game associations and public reading. Zero posts exist at the read-only snapshot. This is a shipped capability with adoption not yet demonstrated, not a reason to build uploads immediately.

Activation uses existing VarsityVue graphics/photos with documented display rights. Select useful content, publish through existing tools only under operational authorization, link relevant schools/games and assess audience return plus owner publishing/review effort in the [operations plan](2026-season-operations-plan.md). This documentation task publishes nothing.

Phase 2 remains conditional on actual Phase 1 use and demonstrated value, adequate moderation capacity and acceptable storage/permission burden. Preferred first scope, generally post-season: selected verified contributors → one image → provenance/display permission → administrator review → publish/reject. Define contributor scope, active-account denial, rights, retention, abuse handling and safe media validation before a separate implementation release.

Broad fan uploads, video hosting, comments, reactions and algorithmic ranking remain DEFERRED. Do not describe the older “School Spirit” moderated fan concept as committed Phase 2 scope. No phase advancement merely because the code foundation exists.
