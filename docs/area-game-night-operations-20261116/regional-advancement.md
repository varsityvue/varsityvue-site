## Per-slot advancement checklist

1. Confirm both source Game IDs above; inspect the actual verified final, both explicit scores, publication revision and supporting evidence. Pending/live/partial/tied/disputed/unverified/no-contest results do not produce a normal advancing winner. A forfeit needs the official winner slug and authoritative outcome evidence.
2. Reopen Playoff Central and admin readiness. The pair is confirmed only when both source results establish it; never copy an external bracket’s speculative next-round team.
3. Use the existing canonical repository schedule workflow for a Regional Semifinal record: 2026 season, correct next playoff week, exact division/region, confirmed participant school slugs, unique Game ID, reviewed scoring-slot orientation, source attribution and neutral-site/designated-side presentation. Reuse an existing matching record; never create a second source of truth. Verify week against the existing calendar; do not invent date/time/venue. Unknown schedule details remain TBD.
4. Research kickoff instant with CST offset, venue and city; retain attribution. A confirmed pair does not establish a kickoff or venue. Require owner approval for the canonical release. Do not publish hypothetical participants.
5. Prepare the corresponding private canonical_game_identity row from the released canonical Game’s home/away slugs. Obtain explicit production-write approval; never copy Area identities to a new Regional Game ID or repeat the completed La Villa–Chilton repair.
6. After the separately approved release, verify one Game Center, both school hubs/schedules, Playoff Central, Regional readiness and exact identity registration. All 48 rows remain in this ledger until their publication and source requirements are reconciled.
7. If either Area winner reverses, stop downstream publication; inspect this exact destination and every further descendant in the existing bracket. Reconcile any published Regional Game, school schedules, scoring slots, pending reports and downstream score state through reviewed workflows. A change to a participant must never silently transfer an existing score. If an affected downstream game already has a result, pause for an explicit owner reconciliation decision.
