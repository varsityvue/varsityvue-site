# Solo verification and publication checklist

Owner only. This describes existing authorized tools, not permission for this preparation session to write production. No continuous LIVE coverage is required. Contributor assignments do not establish availability.

## Open at most four tabs

1. Working solo queue, at the first unfinished row for the current owner block.
2. Existing `/internal/scoring?week=13` editor; use each row’s preselected-game link.
3. Matching MaxPreps division bracket, or the pending report / existing Missing Scores evidence.
4. An authoritative school/athletics final or an independent corroborating report when needed.

Scan the same division source once for several games. Do not open 96 school pages in advance. All 3A/4A work is final-only. The three assignment-linked 2A games get first attention only when a final is actually available. No second operator or review shift exists.

## One pass per available candidate

1. Match exact Game ID, both schools, Area round and scoring-slot orientation. Home/away are storage slots, not physical sidelines. Confirm the current state and revision in the real editor. A predicted bracket advancement is not a final.
2. Require both explicit scores and an explicit FINAL label. Blank never means zero; zero is valid only when supplied explicitly. Normal playoff finals must have an untied winner. Partial/live/tied/disputed/no-contest results do not establish a normal advancing winner. Forfeit/no-contest outcomes require the existing reviewed exceptional-outcome workflow and authoritative evidence; do not improvise a numeric score.
3. Use one directly attributable official school/athletics final or official outcome notice after matching game/date, or two independently sourced matching final reports. The owner may review an official final alone; no second staff sign-off is required. With nonofficial reports, independence refers to reporting origin, not different website branding. UIL-linked MaxPreps, SI embeds and copied reports are not independent corroboration. DCTX may include user updates. Search snippets and a source’s weight/consensus alone are insufficient.
4. Spend at most three minutes looking for missing corroboration during a bounded block. If unavailable, mark the reason and next owner block, then continue to the next 2A game. Never infer FINAL from K+ time, expected duration, missing updates or a scheduled next-round participant.
5. Choose exactly one existing path: approve a genuinely supported pending report; review existing Score Scout evidence with its explicit confirmation; or enter the already verified final directly in the preselected operational editor. Do not re-enter one result into multiple evidence/submission systems merely to create a second source. Save a single concise source note and observation time; keep one working log.
6. Read the two score slots again, complete explicit FINAL confirmation and submit once. On stale/conflict response, refresh the current result and review evidence; never auto-retry or overwrite a newer result. Existing authentication, role checks, revision safeguards and audit requirements remain unchanged.
7. Read back the Game Center and both school schedule links from that row. At block end check Playoff Central once for the newly completed Regional pairs. The app invalidates these paths; a persistent mismatch is a defect to investigate, not a reason to re-submit the score.
8. Mark that row published or deferred and move on. A successful final advances the bracket winner automatically. It does not create a Regional Game Center or database identity. Follow only the newly eligible destination in the 48-slot ledger.

## Solo stop / resume rules

- P0 schedule research: La Villa–Chilton stays outside a fictional kickoff window. Retain TBD until reliably confirmed.
- P1/P2: all available 2A finals before discretionary P3 work. Not-yet-played 2A games do not block review of an earlier 3A/4A final. Within the current block, first check available finals for De Leon, Cisco and Goldthwaite; then favor a Regional companion if the other source final is already verified; otherwise follow the window list.
- P3: all 64 3A/4A games are final-only batches, generally the next morning. If a batch is not complete at the time cap, retain the next unfinished row; it need not be checked every 15 minutes.
- Backlog: stop at the owner block limit. Write one carry-forward line with Game ID, reason, evidence already found and next block. No staffing request, late-night monitoring promise or assumed contributor handoff.
- Authentication unavailable: keep the evidence privately and defer publication. Do not create accounts, change permissions or use an unapproved public path.
- Conflicting scores / missing official outcome: leave unverified and revisit after a clearer authoritative report. The same owner handles later review; do not lower the standard to empty the queue.
- Winner-reversing correction: use the existing audited correction screen with reason/current revision. Freeze the affected Regional destination and descendants; reconcile any published downstream participant, score identity, pending report or score before continuing. Never silently transfer a score to a different school.

## Automation boundary

The existing missing-score worker is eligible only four hours after a known kickoff and within its historical window. It depends on current provider/worker configuration and can miss or misclassify sources. La Villa–Chilton cannot enter a kickoff-based discovery window while kickoff is TBD. Evidence remains a candidate until explicitly reviewed. Do not invoke `/api/cron/product-emails` as a manual score helper: it also queues/drains emails and writes operational state. Do not run or enable ingestion, paid providers or automatic publication during this read-only preparation.
